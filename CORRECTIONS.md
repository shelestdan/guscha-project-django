# Исправления архитектуры Docker

## Что было неправильно

Изначально были внесены изменения, которые не соответствовали существующей архитектуре проекта:

### ❌ Ошибка 1: Создан nginx.conf в guscha_django_frontend
**Проблема:**
- Создан файл `guscha_django_frontend/nginx.conf`
- В проекте уже есть настроенный nginx в `guscha_django/config/nginx.conf`
- Дублирование конфигурации

**Исправлено:** ✅ Файл удалён

---

### ❌ Ошибка 2: Добавлен отдельный сервис frontend в docker-compose
**Проблема:**
- Добавлен сервис `frontend` с nginx на порту 3000
- Проект использует единую точку входа через основной nginx на порту 80
- Это создавало дублирование и путаницу

**Исправлено:** ✅ Сервис frontend удалён из docker-compose.dev.yml

---

### ❌ Ошибка 3: Создан Dockerfile для фронтенда
**Проблема:**
- Создан `guscha_django_frontend/Dockerfile`
- В архитектуре проекта фронтенд собирается локально (`npm run build`)
- Docker не используется для сборки фронтенда
- Собранные файлы размещаются в `static_root` Django проекта

**Исправлено:** ✅ Dockerfile удалён

## Правильная архитектура

### Как работает проект:

```
┌─────────────────────────────────────────────┐
│   Пользователь                              │
└───────────────┬─────────────────────────────┘
                │
                ▼
        ┌───────────────┐
        │  nginx:80     │  ← Единая точка входа
        └───────┬───────┘
                │
        ┌───────┴───────────────────┐
        │                           │
        ▼                           ▼
┌──────────────┐          ┌──────────────┐
│ /var/www/    │          │ Django API   │
│ react/       │          │ (proxy)      │
│ (static)     │          │ /api/        │
└──────────────┘          │ /admin/      │
                          └──────────────┘
```

### Сервисы в docker-compose:

1. **nginx** (порт 80)
   - Раздаёт React статику из `/var/www/react`
   - Проксирует API запросы к Django

2. **django** (порт 8000)
   - Backend API
   - Админка

3. **db** (PostgreSQL)
4. **redis** (кэширование)
5. **telegram-bot** (отдельный сервис)
6. **postgres-exporter** (метрики)

### Frontend сборка:

- React приложение собирается **локально** через `npm run build`
- Собранные файлы размещаются в `static_root` Django проекта
- Nginx раздаёт эти файлы из `/var/www/react`
- **Docker не используется** для сборки фронтенда
- Отдельного контейнера с фронтендом **нет**
