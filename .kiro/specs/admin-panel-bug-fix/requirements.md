# Требования к исправлению ошибки админ-панели

## Введение

Данная функция направлена на исправление критической ошибки в админ-панели Django, которая возникает при попытке редактирования товаров. Ошибка связана с конфликтом между аннотированными полями в queryset и свойствами модели Product.

## Требования

### Требование 1

**Пользовательская история:** Как администратор, я хочу иметь возможность редактировать товары в админ-панели без ошибок, чтобы управлять каталогом товаров.

#### Критерии приемки

1. КОГДА администратор открывает страницу редактирования товара ТОГДА система НЕ ДОЛЖНА выдавать ошибку AttributeError: property 'review_count' of 'Product' object has no setter
2. КОГДА администратор сохраняет изменения товара ТОГДА система ДОЛЖНА успешно сохранить данные без ошибок
3. КОГДА администратор просматривает список товаров ТОГДА система ДОЛЖНА корректно отображать количество отзывов для каждого товара
4. КОГДА система выполняет запросы к базе данных ТОГДА она НЕ ДОЛЖНА пытаться установить значения для свойств только для чтения

### Требование 2

**Пользовательская история:** Как администратор, я хочу видеть корректную статистику по отзывам в списке товаров, чтобы понимать популярность товаров.

#### Критерии приемки

1. КОГДА администратор просматривает список товаров ТОГДА система ДОЛЖНА показывать точное количество одобренных отзывов
2. КОГДА администратор сортирует товары по количеству отзывов ТОГДА система ДОЛЖНА использовать корректные данные для сортировки
3. КОГДА система вычисляет средний рейтинг ТОГДА она ДОЛЖНА использовать только одобренные отзывы
4. ЕСЛИ у товара нет отзывов ТОГДА система ДОЛЖНА отображать "Нет отзывов" вместо ошибки

### Требование 3

**Пользовательская история:** Как разработчик, я хочу иметь оптимизированные запросы к базе данных в админ-панели, чтобы обеспечить хорошую производительность.

#### Критерии приемки

1. КОГДА система загружает список товаров ТОГДА она ДОЛЖНА использовать select_related для связанных моделей
2. КОГДА система вычисляет статистику отзывов ТОГДА она ДОЛЖНА использовать аннотации вместо множественных запросов
3. КОГДА администратор открывает страницу товара ТОГДА система ДОЛЖНА предзагружать связанные изображения и размеры
4. ЕСЛИ требуется вычисление агрегатных данных ТОГДА система ДОЛЖНА использовать database-level агрегацию
