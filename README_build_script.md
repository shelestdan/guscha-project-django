# Улучшенный скрипт сборки фронтенда

## Описание

Скрипт `build_frontend_improved.ps1` обеспечивает полную автоматизацию сборки React-фронтенда с интеграцией Docker-контейнеров для бесшовного обновления в продакшене.

## Возможности

✅ **Автоматическая сборка React-приложения**
✅ **Копирование файлов в обе директории** (static/ и static_root/)
✅ **Резервное копирование важных файлов** (axiosConfig.js, админские файлы)
✅ **Интеграция с Docker-контейнерами**
✅ **Выполнение collectstatic через Django**
✅ **Перезапуск nginx для обновления кэша**
✅ **Проверка доступности приложения**
✅ **Подробное логирование с цветами**

## Использование

### Базовый запуск (полная сборка с Docker)
```powershell
.\build_frontend_improved.ps1
```

### Параметры запуска

```powershell
# Пропустить сборку фронтенда (использовать существующую)
.\build_frontend_improved.ps1 -SkipBuild

# Режим разработки (без Docker)
.\build_frontend_improved.ps1 -DevMode

# Пропустить Docker интеграцию
.\build_frontend_improved.ps1 -SkipDocker

# Подробное логирование
.\build_frontend_improved.ps1 -Verbose

# Комбинирование параметров
.\build_frontend_improved.ps1 -SkipBuild -Verbose
```

## Этапы выполнения

### Шаг 1: Сборка React-фронтенда
- Проверка package.json
- Установка npm зависимостей
- Сборка приложения (`npm run build`)
- Проверка результата сборки

### Шаг 2: Подготовка директорий Django
- Создание необходимых директорий
- Проверка прав доступа
- Резервное копирование важных файлов
- Очистка старых файлов

### Шаг 3: Копирование файлов фронтенда
- Копирование в `static/` (для разработки)
- Копирование в `static_root/` (для продакшена)
- Восстановление важных файлов
- Копирование axiosConfig.js

### Шаг 4: Обновление index.html файлов
- Добавление ссылки на axiosConfig.js
- Обновление файлов в обеих директориях

### Шаг 5: Интеграция с Docker-контейнерами
- Проверка состояния контейнеров
- Выполнение `collectstatic` в Django
- Перезапуск nginx
- Проверка доступности приложения

```

```

## Режимы работы

### Продакшен (по умолчанию)
- Полная сборка фронтенда
- Копирование в обе директории
- Интеграция с Docker
- Перезапуск контейнеров

### Разработка (-DevMode)
- Сборка фронтенда
- Копирование только в static/
- Без Docker интеграции

### Быстрое обновление (-SkipBuild)
- Использование существующей сборки
- Копирование и Docker интеграция

## Устранение неполадок

### Docker не запущен
```
✗ Docker не запущен или недоступен
Запустите Docker Desktop или используйте параметр -DevMode
```
**Решение:** Запустите Docker Desktop или используйте `-DevMode`

### Ошибка сборки npm
```
✗ Ошибка сборки: [детали ошибки]
```
**Решение:** Проверьте package.json и зависимости

### Контейнеры не запускаются
```
✗ Таймаут ожидания запуска контейнера
```
**Решение:** Проверьте docker-compose.yml и логи контейнеров
