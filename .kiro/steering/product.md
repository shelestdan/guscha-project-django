# Product Overview

Guscha is a full-stack e-commerce web application built with Django REST Framework backend and React frontend. The application provides a complete online shopping experience with product catalog, user accounts, shopping cart, order management, and address management functionality.

## Key Features

- **Product Management**: Catalog with product listings, details, and search
- **User Authentication**: Custom user model with email-based authentication
- **Shopping Cart**: Session-based cart functionality
- **Order Processing**: Complete order lifecycle management
- **Address Management**: Shipping and billing address handling with Google Maps integration
- **Admin Interface**: Django admin with Jazzmin theme for content management

## Target Users

- **End Users**: Customers browsing and purchasing products
- **Administrators**: Store managers using Django admin interface
- **Developers**: Team members maintaining and extending the platform

## Business Context

The application is designed for Russian-speaking markets (default language: ru-ru) and includes localized features like phone number validation and address formatting.
